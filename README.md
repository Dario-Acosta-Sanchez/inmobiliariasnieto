# García Nieto Inmobiliaria

Escaparate de inmuebles de García Nieto Inmobiliaria en Córdoba.

🔗 **[inmobiliariasnieto.puntozerosl.es](http://inmobiliariasnieto.puntozerosl.es/)**

![Vista previa](.github/preview.jpg)

## Qué incluye

- Listado de viviendas en venta y alquiler con filtros y buscador
- Inmuebles cargados en tiempo real desde la base de datos
- Conectado con el [panel de gestión](https://github.com/Dario-Acosta-Sanchez/gestionnieto)
